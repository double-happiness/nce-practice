## 1. 快速开始

```bash
npm install    # 首次需要联网，仅安装 express
# 从 Git 克隆后需拉取原声 MP3（Git LFS，约 550MB）：
# git lfs install && git lfs pull
npm start      # 默认 http://localhost:3737
```

浏览器打开上述地址即可。学习记录保存在本机 `data/` 目录，**无需注册账号、无需联网**（服务启动后断网仍可使用，见下文 FAQ）。

## 2. 界面怎么组织

顶栏分为四组，对应学习阶段：

| 分组 | 包含功能 | 适合什么时候用 |
|------|----------|----------------|
| **学** | 📖 教材学习、📕 查词典、🎓 雅思备考 | 学新课、查词、看语法；备考雅思 |
| **练** | ✏️ 刷题、🎧 听写、🔀 句型转换、💬 情景对话、📝 阶段测验 | 巩固、输出训练 |
| **复习** | 🔁 间隔复习、🔤 单词（词表/背单词/词汇测） | 抗遗忘、补漏洞 |
| **我的** | 📊 薄弱分析、🎯 学习计划、💾 数据备份 | 看进度、定计划、备份 |

**🏠 今日学习**（首页）是调度中心：今日目标、到期错题、薄弱语法、词汇量、继续上次课程、快捷查词——建议每天从这里开始。

首次进入首页会显示简短欢迎引导；完整说明见 **📖 使用说明** 卡片或本页。

## 4. 推荐学习路径

### 4.1 零基础 · 第一册（约 45–60 分钟/天）

以 **当前 1 课** 为中心，完成「听→说→读→写→记」闭环：

| 顺序 | 功能 | 建议时长 | 目标 |
|------|------|----------|------|
| 1 | 📖 教材学习（含 🎧 原声） + ✏️ 练本课语法 | 15 min | 听懂原声、读懂课文、掌握语法点 |
| 2 | 🎧 听写（选本课） | 10 min | 精听 + 拼写 |
| 3 | 💬 情景对话 或 朗读精读 | 10 min | 开口、语调 |
| 4 | 🔀 句型转换 | 10 min | 中译英、句型改写 |
| 5 | 🔤 背单词 + 🔁 复习到期错题 | 10 min | 词汇 + 抗遗忘 |

- **周日**：不学新课，做 **📝 阶段测验**（本周 6 课区间），错题自动进复习。
- **第四册**：每学完 12 课可用预设「L1–12 / L13–24 …」20 题模考；全书复习可用「全书模考 · 40题」。
- **每月**：做一次 👂/📖 词汇量测试，在 **📈 词汇趋势** 看变化。
- 详细计划说明见应用内 **🎯 学习计划** 页。

### 4.2 有基础 · 第二册

- 教材学习按课推进；刷题/句型转换与当前课同步。
- 薄弱分析出现红色语法点时，用首页 **专练 10 题** 或刷题筛选该语法。
- 查词典展开详情，看固定搭配与课内句型。

### 4.3 只补某一技能

| 目标 | 优先用 |
|------|--------|
| 语法弱 | 刷题 + 句型转换 + 间隔复习 |
| 词汇弱 | 背单词 + 听/读词汇量 + 查词典 |
| 听力弱 | 听写 + 听力词汇量 |
| 口语弱 | 情景对话 + 听写跟读 |
| 考前复盘 | 阶段测验 + 薄弱分析 |

## 5. 常用操作提示

### 5.1 🔊 发音与原声课文

全站 **🔊** 自动按优先级选择音源：

1. **新概念英音原声**（与 LRC 课文句一致时）  
2. **真人单词发音**（单词/短短语）  
3. **浏览器 TTS**（以上都没有时）

**教材页 · 🎧 原声课文**：整课 MP3 播放，点击某句可跳转并高亮；1–4 册共 276 课原声随项目内置，**无需联网**。

顶栏 🔊 语速下拉只影响 TTS；原声按录音原速播放。  
详细说明见 [原声与发音.md](原声与发音.md)。

### 5.3 💬 情景对话（二级目录）

左侧 **场景目录** 为两层：

1. **大类**（8 个）：居家社交、餐饮购物、出行旅游、职场学习、住房物业、健康运动、生活服务、休闲文娱  
2. **具体场景**（73 类）：如「打电话」「IT工作」「机场」等  

点击大类展开/收起，再点场景，右侧列出该场景下的对话练习。顶部搜索框可搜 **大类名或场景名**。

### 5.4 其他技巧

- **查词**：课文单词点 📕；选中英文短语也会弹出查词；词典内按 `/` 快速聚焦搜索框。
- **深链**：查词典支持 `#dictionary?q=umbrella`；教材支持 `#learn?book=1&lesson=3`。
- **生词本**：词表/词典/教材 ☆ 收藏，在 **词表** 子页复习。
- **错词复习**：词汇测试后可「逐个查词典复习」；首页会提示继续进度。
- **多档案**：数据备份页可切换档案（家人共用一台电脑时）。

## 6. 🎓 雅思备考（A2 → 7.0）

入口：**学 → 🎓 雅思备考**。面板内有五个子页：**总览计划 / 词汇 / 写作 / 口语 / 记录**。

> **先说清楚时间线**：从 A2 到雅思 7.0 要跨 B1、B2、C1 三档，大约需要 **600 小时**有效学习，相当于 26 周里**每天 3–3.5 小时**。这个节奏非常紧，所以计划里设了三个检查点（见 6.4），没跟上时会给出调整建议。每天投入不到 3 小时的话，建议一开始就把考试日往后放，或者先把目标定在 6.5。

### 6.1 开启备考

1. 第一次进入会看到开启引导，默认 **A 类（学术类）**、考试日 **2027-05-24**、目标总分 **7.0**，三项都可以先改再开启，开启后也能修改。
2. **A 类 / G 类**的区别在写作 Task 1：A 类写图表描述，G 类（培训类）写书信；Task 2 和口语两类相同。
3. 开启当天记为**备考开始日**。计划按「开始日 → 考试日」换算实际周数（最少 4 周、最多 52 周），26 周模板按比例压缩或拉伸到实际周数，所以**改了考试日，计划会自动重排**。
4. 开启后，🏠 首页会显示考试倒计时卡片。

### 6.2 26 周三阶段练什么

计划每周 5–8 项任务，日均约 180–210 分钟。

| 阶段 | 模板周 | 水平目标 | 主要练什么 |
|------|--------|----------|------------|
| **基础期** | 第 1–8 周 | A2 → B1 | NCE2 精读 + 本课题、🔀 句型转换、🎧 NCE2 听写、🔤 背单词（NCE2 词 + 雅思学术通用 / B1 词）、💬 情景对话、🔁 间隔复习；第 3 周起加口语 Part 1，第 6 周起每周 1 篇 Task 1 入门 |
| **专项期** | 第 9–20 周 | B1 → B2 | NCE3 精读 + 阅读理解、听力理解、NCE3 听写、每周 2 个雅思话题的词、Task 1 每周 2 篇、Task 2 每周 2 篇、口语 Part 1/2/3 每天练、学术对话；外部资料：剑雅听力、阅读每周各 1 套 |
| **冲刺期** | 第 21–26 周 | B2 → C1 | NCE4 精读、Task 2 每周 5 篇、Task 1 每周 3 篇、每天一套口语全真模拟、📝 阶段测验（第四册模考）、每周 1 次雅思词汇诊断；外部资料：剑雅全套模考每周 2 套；第 26 周是考试周，降量复盘 |

「剑雅」指《剑桥雅思》真题集，系统里**不提供**，需要自备。

### 6.3 今日任务怎么用

**总览计划**页显示：考试倒计时、阶段进度、本周重点、今日任务清单、未来两周概要和检查点。

- **系统内任务**：按你在各功能里的真实练习记录**自动统计**，做够目标量自动标为完成，不用手动打卡。点任务旁的 **「去做 →」** 直接跳到对应功能或雅思子页。
- **外部资料任务**（剑雅听力、阅读、全套模考等）：系统统计不到，做完后在今日任务里**手动打勾**，勾选记在当天，勾错了可以取消。只有外部资料任务能手动打勾。
- **🎯 学习计划**页新增「**雅思**」强度预设。雅思写作计入「写」，雅思口语计入「说」，背雅思词汇计入「记」，都会算进今日目标。

### 6.4 检查点：怎么看，没达标怎么办

模板第 **8、14、20** 周各有一个检查点（改了考试日后会换算到对应的实际周）：

| 检查点 | 模板周 | 雅思词汇诊断 | 写作近 3 次自评均值 | 口语近 3 次自评均值 |
|--------|--------|--------------|---------------------|---------------------|
| B1 检查点 | 第 8 周 | B1 段覆盖率 ≥ 70% | ≥ 5.0 | ≥ 5.0 |
| B2 中期检查 | 第 14 周 | B2 段覆盖率 ≥ 60% | ≥ 5.5 | ≥ 5.5 |
| 冲刺前检查 | 第 20 周 | C1 段覆盖率 ≥ 50% | ≥ 6.5 | ≥ 6.5 |

- 还没到的检查点不做判定；到了对应周，系统取**最近一次雅思词汇诊断**的对应段覆盖率，以及**写作、口语各自近 3 次自评均值**，三项全部达标为通过，否则为未达标。
- 建议在检查点那一周之前做一次词汇诊断，并保证写作、口语都有近期记录，判定才有意义。
- **没达标时**会给出三条建议，任选其一或组合：
  1. 把 🎯 学习计划切到「雅思」或「冲刺」预设，加大每日练习量；
  2. 按差距把考试日推迟 4–8 周（建议里会给出具体日期）；
  3. 把目标分暂时调到 6.5。
- 建议**只做提示，不会自动修改**任何设置，改不改由你决定。

### 6.5 雅思词汇：背诵与诊断

- **词表**：约 720 词，分三部分：**学术通用词 241 个**，**社会类话题词约 240 个**，**自然科技类话题词约 240 个**；话题涵盖教育、环境、科技、健康、工作、犯罪、媒体、城市、全球化、政府、文化、科学。每词标 CEFR 级别（B1–C2），带音标、中文释义、原创例句和常用搭配，可按话题、CEFR 级别浏览。
- **卡片背诵 / 拼写**：和「🔤 背单词」共用掌握度、间隔复习与今日统计。
- **📕 查词典**也能查到雅思词；同一个词在教材里出现过时，优先显示教材释义。
- **雅思词汇诊断**：从 B1、B2、C1 三段各抽 10 词，看英文选中文释义（4 选 1），得出各段覆盖率和整体覆盖率，并列出错词；出题后 30 分钟内提交有效。每次结果都会留档，检查点用的就是最近一次结果。
- 诊断**不影响**「🌐 总词汇量」测试的口径，两者的历次成绩互不干扰。**🧭 我的水平**页的 CEFR 现在分到 Pre-A1 / A1 / A2 / B1 / B2 / C1；总词汇量测试的高段词量有限，C1 以上请以雅思词汇诊断为准。

### 6.6 写作怎么练

**题库**（题目、范文全部原创）：

| 类型 | 数量 | 说明 |
|------|------|------|
| Task 2 议论文 | 20 题 | 观点类、讨论类、问题解决、利弊、双问题 5 种题型各 4 题；附中文题意、思路、提纲、常用表达 |
| Task 1 A 类图表 | 8 题 | 柱状图、折线图、饼图、表格各 2 题 |
| Task 1 G 类书信 | 6 封 | 正式、半正式、非正式各 2 封 |

所有题目都带范文（7–7.5 分水平）。

**练习流程**：选题 → 计时写作 → 提交 → 四维自评 → 范文对照 → 得出本篇分数。

1. **计时**：Task 1 计 20 分钟，Task 2 计 40 分钟，和考场时间分配一致；写作时实时显示字数，草稿自动保存在当前浏览器里。
2. **字数**：Task 1 至少 150 词，Task 2 至少 250 词，不足时提交后会提示（考试中字数不足会扣分）。
3. **范文在提交前隐藏**，避免先看答案。
4. **四维自评**：Task 1 看任务完成（TA）、连贯与衔接（CC）、词汇丰富度（LR）、语法多样性与准确性（GRA）四项；Task 2 把「任务完成」换成任务回应（TR）。每一项都有 **4 / 5 / 6 / 7 / 8** 五档说明和一份检查清单；4 分档对应 A2 起步阶段的常见水平，刚开始练时打 4 分很正常。
   - 打分方法：逐条对照检查清单，再选最贴近自己文章的那一档；介于两档之间可以给半分（如 5.5）；拿不准时选低一档。
5. **本篇分数** = 四维平均后**向下取整到 0.5**。例如四项 6 / 6 / 5.5 / 5.5，平均 5.75，记为 **5.5**。自评通常偏乐观，向下取整更保守。
6. **范文对照**：重点看结构（Task 1 有没有概述总体趋势，Task 2 立场是否贯穿全文）、段落展开和用词，把好的表达记下来。
7. 每次提交都会保存（原文、字数、用时、四维分和本篇分数），在**记录**子页查看历史。

### 6.7 口语怎么练

**题库**（参考答案全部原创）：Part 1 共 16 个话题 × 4 题；Part 2 题卡 16 张，每张配 4 道 Part 3 追问；全部带参考答案。

| 部分 | 流程 |
|------|------|
| Part 1 | 围绕日常话题逐题作答 |
| Part 2 | 看题卡准备 **60 秒**（可记要点）→ 作答 **120 秒**倒计时 |
| Part 3 | 围绕同一题卡话题回答追问，练展开和论证 |

- **录音回听**：浏览器支持时可以边答边录音，答完回听。首次使用浏览器会询问麦克风权限。
- **录音只留在本机浏览器里**：不上传、不保存到硬盘，关闭或刷新页面后就没有了。系统只记录作答时长、自评分和你写的备注。
- **四维自评**：流利度与连贯性（FC）、词汇丰富度（LR）、语法多样性与准确性（GRA）、发音（P），同样是 4–8 分五档说明 + 检查清单，打分方法和写作相同，本题分数同样是四维平均后向下取整到 0.5。发音最难自评，建议先回听录音再打分。
- 打完分再看**参考答案**，对照自己少说了什么、哪些表达可以替换。

### 6.8 分数估算只是粗估

**🧭 我的水平**页和雅思总览会显示一个雅思总分估算，总分按官方规则四舍五入到 0.5（.25 进为 .5，.75 进为整数）。它依据的是你自己的写作、口语自评和雅思词汇诊断，本期系统里**没有**雅思题型的听力、阅读练习，所以这个数字**只是粗估**，不能代替真实模考。冲刺期请以剑雅全套模考的成绩为准。

## 9. 常见问题 FAQ

**Q：打不开页面？**  
A：确认终端里 `npm start` 已运行，浏览器访问 `http://localhost:3737`。

**Q：刷新后进度还在吗？**  
A：在。进度写在本地 JSON；除非清空数据或删 `data/`。

**Q：没有声音？**  
A：检查系统音量与浏览器权限。课文句优先播 **原声 MP3**；单词播真人库或 TTS。TTS 需 Mac/Windows 已安装英文语音。若原声无法播放，可能是克隆时未执行 `git lfs pull`（见 [原声与发音.md](原声与发音.md)）。

**Q：🔊 为什么是机器声而不是原声？**  
A：内容与 LRC 课文句不完全一致时会降级为 TTS；单词单独点击通常播单词发音而非整句原声。

**Q：情景对话左侧显示「没有匹配的场景」？**  
A：硬刷新页面（`Cmd+Shift+R`）；若从 Git 克隆，确认已 `git lfs install && git lfs pull` 并重启 `npm start`。侧栏应显示 8 个大类，其下为具体场景。

**Q：两台设备怎么同步？**  
A：系统无云同步。用 **数据备份** 导出 JSON，拷到另一台机器导入。

**Q：词典里全局词为什么没有教材例句？**  
A：全局词库约 2600 词，仅教材词有课内例句与句型；展开会标注「全局词库 · 仅词库释义」。

**Q：如何清除「知道了」后的欢迎引导？**  
A：浏览器清除站点数据中的 `nce-guide-dismissed`；或删对应 localStorage 项后刷新。

**Q：雅思口语录音会上传吗？**  
A：不会。录音只在本机浏览器里回听，不上传、不保存，关闭或刷新页面即消失；系统只记录作答时长和自评分。

**Q：雅思口语页没有录音功能？**  
A：浏览器不支持录音时会隐藏录音，其余练习照常可用。请确认已允许麦克风权限；另外浏览器只在 `localhost` 或 HTTPS 页面下开放麦克风，用局域网 IP 通过 http 访问时无法录音。

**Q：雅思分数估算准吗？**  
A：只是粗估。它依据的是你的自评分和雅思词汇诊断，没有雅思题型的听力、阅读成绩参与，请以剑雅全套模考为准。

**Q：我是开发者，如何加题/加课？**  
A：见 [README.md](../README.md)「如何扩充题库」与 `docs/changes/` 变更说明。
