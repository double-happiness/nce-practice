## 1. 快速开始

```bash
npm install    # 首次需要联网，仅安装 express
# 从 Git 克隆后需拉取原声 MP3（Git LFS，约 550MB）：
# git lfs install && git lfs pull
npm start      # 默认 http://localhost:3737
```

浏览器打开上述地址即可。学习记录保存在本机 `data/` 目录，**无需注册账号、无需联网**（服务启动后断网仍可使用，见下文 FAQ）。

## 2. 界面怎么组织

顶栏分为四组，对应学习阶段：

| 分组 | 包含功能 | 适合什么时候用 |
|------|----------|----------------|
| **学** | 📖 教材学习、📕 查词典、🎓 雅思备考 | 学新课、查词、看语法；备考雅思 |
| **练** | ✏️ 刷题、🎧 听写、🔀 句型转换、💬 情景对话、📝 阶段测验 | 巩固、输出训练 |
| **复习** | 🔁 间隔复习、🔤 单词（词表/背单词/词汇测） | 抗遗忘、补漏洞 |
| **我的** | 📊 薄弱分析、🎯 学习计划、💾 数据备份 | 看进度、定计划、备份 |

**🏠 今日学习**（首页）是调度中心：今日目标、到期错题、薄弱语法、词汇量、继续上次课程、快捷查词——建议每天从这里开始。

首次进入首页会显示简短欢迎引导；完整说明见 **📖 使用说明** 卡片或本页。

## 4. 推荐学习路径

### 4.1 零基础 · 第一册（约 45–60 分钟/天）

以 **当前 1 课** 为中心，完成「听→说→读→写→记」闭环：

| 顺序 | 功能 | 建议时长 | 目标 |
|------|------|----------|------|
| 1 | 📖 教材学习（含 🎧 原声） + ✏️ 练本课语法 | 15 min | 听懂原声、读懂课文、掌握语法点 |
| 2 | 🎧 听写（选本课） | 10 min | 精听 + 拼写 |
| 3 | 💬 情景对话 或 朗读精读 | 10 min | 开口、语调 |
| 4 | 🔀 句型转换 | 10 min | 中译英、句型改写 |
| 5 | 🔤 背单词 + 🔁 复习到期错题 | 10 min | 词汇 + 抗遗忘 |

- **周日**：不学新课，做 **📝 阶段测验**（本周 6 课区间），错题自动进复习。
- **第四册**：每学完 12 课可用预设「L1–12 / L13–24 …」20 题模考；全书复习可用「全书模考 · 40题」。
- **每月**：做一次 👂/📖 词汇量测试，在 **📈 词汇趋势** 看变化。
- 详细计划说明见应用内 **🎯 学习计划** 页。

### 4.2 有基础 · 第二册

- 教材学习按课推进；刷题/句型转换与当前课同步。
- 薄弱分析出现红色语法点时，用首页 **专练 10 题** 或刷题筛选该语法。
- 查词典展开详情，看固定搭配与课内句型。

### 4.3 只补某一技能

| 目标 | 优先用 |
|------|--------|
| 语法弱 | 刷题 + 句型转换 + 间隔复习 |
| 词汇弱 | 背单词 + 听/读词汇量 + 查词典 |
| 听力弱 | 听写 + 听力词汇量 |
| 口语弱 | 情景对话 + 听写跟读 |
| 考前复盘 | 阶段测验 + 薄弱分析 |

## 5. 常用操作提示

### 5.1 🔊 发音与原声课文

全站 **🔊** 自动按优先级选择音源：

1. **新概念英音原声**（与 LRC 课文句一致时）  
2. **真人单词发音**（单词/短短语）  
3. **浏览器 TTS**（以上都没有时）

**教材页 · 🎧 原声课文**：整课 MP3 播放，点击某句可跳转并高亮；1–4 册共 276 课原声随项目内置，**无需联网**。

顶栏 🔊 语速下拉只影响 TTS；原声按录音原速播放。  
详细说明见 [原声与发音.md](原声与发音.md)。

### 5.3 💬 情景对话（二级目录）

左侧 **场景目录** 为两层：

1. **大类**（8 个）：居家社交、餐饮购物、出行旅游、职场学习、住房物业、健康运动、生活服务、休闲文娱  
2. **具体场景**（73 类）：如「打电话」「IT工作」「机场」等  

点击大类展开/收起，再点场景，右侧列出该场景下的对话练习。顶部搜索框可搜 **大类名或场景名**。

### 5.4 其他技巧

- **查词**：课文单词点 📕；选中英文短语也会弹出查词；词典内按 `/` 快速聚焦搜索框。
- **深链**：查词典支持 `#dictionary?q=umbrella`；教材支持 `#learn?book=1&lesson=3`。
- **生词本**：词表/词典/教材 ☆ 收藏，在 **词表** 子页复习。
- **错词复习**：词汇测试后可「逐个查词典复习」；首页会提示继续进度。
- **多档案**：数据备份页可切换档案（家人共用一台电脑时）。

## 6. 🎓 雅思备考（A2 → 7.0）

入口：**学 → 🎓 雅思备考**。面板内有八个子页：**总览计划 / 📚 基础 / 词汇 / 🎧 听力 / 📖 阅读 / 写作 / 口语 / 记录**。

> **先说清楚时间线**：从 A2 到雅思 7.0 要跨 B1、B2、C1 三档，大约需要 **600 小时**有效学习，相当于 26 周里**每天 3–3.5 小时**。这个节奏非常紧，所以计划里设了三个检查点（见 6.4），没跟上时会给出调整建议。每天投入不到 3 小时的话，建议一开始就把考试日往后放，或者先把目标定在 6.5。

### 6.1 开启备考

1. 第一次进入会看到开启引导，默认 **A 类（学术类）**、考试日 **2027-05-24**、目标总分 **7.0**，三项都可以先改再开启，开启后也能修改。
2. **A 类 / G 类**的区别在写作 Task 1：A 类写图表描述，G 类（培训类）写书信；Task 2 和口语两类相同。
3. 开启当天记为**备考开始日**。计划按「开始日 → 考试日」换算实际周数（最少 4 周、最多 52 周），26 周模板按比例压缩或拉伸到实际周数，所以**改了考试日，计划会自动重排**。
4. 开启后，🏠 首页会显示考试倒计时卡片。

### 6.2 26 周三阶段练什么

计划每周 5–10 项任务（站内听力、阅读都是按周累计的任务），日均约 180–210 分钟（第 26 周考试周降到约 90 分钟）。

| 阶段 | 模板周 | 水平目标 | 主要练什么 |
|------|--------|----------|------------|
| **基础期** | 第 1–8 周 | A2 → B1 | NCE2 精读 + 本课题、🔀 句型转换、🎧 NCE2 听写、🔤 背单词（NCE2 词 + 雅思学术通用 / B1 词）、💬 情景对话、🔁 间隔复习；**每周 2 篇 📚 雅思基础知识库**（第 1–4 周核心语法，第 5–8 周功能表达或题型技巧）；第 3 周起加口语 Part 1，**第 5 周起每周 2 个雅思听力 Part 1**（练习模式，练拼写和数字），第 6 周起每周 1 篇 Task 1 入门 |
| **专项期** | 第 9–20 周 | B1 → B2 | NCE3 精读 + 阅读理解、听力理解、NCE3 听写、每周 2 个雅思话题的词、Task 1 每周 2 篇、Task 2 每周 2 篇、口语 Part 1/2/3 每天练、学术对话；**站内雅思听力 Part 2–4 每周 3 个（练习模式）、雅思阅读每周 2 篇（考试模式）**；外部资料：剑雅听力、阅读每周各 1 套 |
| **冲刺期** | 第 21–26 周 | B2 → C1 | NCE4 精读、Task 2 每周 5 篇、Task 1 每周 3 篇、每天一套口语全真模拟、📝 阶段测验（第四册模考）、每周 1 次雅思词汇诊断；**第 21–25 周站内听力考试模式每周 4 个、阅读考试模式每周 3 篇**；外部资料：剑雅全套模考每周 2 套；第 26 周是考试周，降量复盘 |

「剑雅」指《剑桥雅思》真题集，系统里**不提供**，需要自备。站内听力有 20 个 section（Part 2–4 共 15 个）、阅读 17 篇，按专项期和冲刺期的任务量仍会重做做过的题，这是预期内的：重做时练定位速度和复盘错题。

### 6.3 今日任务怎么用

**总览计划**页显示：考试倒计时、阶段进度、本周重点、今日任务清单、未来两周概要和检查点。

- **系统内任务**：按你在各功能里的真实练习记录**自动统计**，做够目标量自动标为完成，不用手动打卡。点任务旁的 **「去做 →」** 直接跳到对应功能或雅思子页。
- **外部资料任务**（剑雅听力、阅读、全套模考等）：系统统计不到，做完后在今日任务里**手动打勾**，勾选记在当天，勾错了可以取消。只有外部资料任务能手动打勾。
- 站内听力、阅读任务按**交卷次数**统计（交卷一个听力 section 或一篇阅读记 1 次），不区分考试模式还是练习模式。
- 基础知识库任务按**交小测的次数**统计（每交一次记 1 次，同一篇做两次也算 2 次）；只标记已读不计数。
- **🎯 学习计划**页新增「**雅思**」强度预设。雅思听力计入「听」，雅思阅读和基础知识库小测计入「读」，雅思写作计入「写」，雅思口语计入「说」，背雅思词汇计入「记」，都会算进今日目标。「读」的单位是「题」，但一篇雅思阅读、一次知识库小测都只算 1 次。
- 🔁 间隔复习里的雅思错题**不计入**今日目标（和其他复习一样）。

### 6.4 检查点：怎么看，没达标怎么办

模板第 **8、14、20** 周各有一个检查点（改了考试日后会换算到对应的实际周）：

| 检查点 | 模板周 | 雅思词汇诊断 | 写作近 3 次自评均值 | 口语近 3 次自评均值 |
|--------|--------|--------------|---------------------|---------------------|
| B1 检查点 | 第 8 周 | B1 段覆盖率 ≥ 70% | ≥ 5.0 | ≥ 5.0 |
| B2 中期检查 | 第 14 周 | B2 段覆盖率 ≥ 60% | ≥ 5.5 | ≥ 5.5 |
| 冲刺前检查 | 第 20 周 | C1 段覆盖率 ≥ 50% | ≥ 6.5 | ≥ 6.5 |

- 还没到的检查点不做判定；到了对应周，系统取**最近一次雅思词汇诊断**的对应段覆盖率，以及**写作、口语各自近 3 次自评均值**，三项全部达标为通过，否则为未达标。
- 建议在检查点那一周之前做一次词汇诊断，并保证写作、口语都有近期记录，判定才有意义。
- **没达标时**会给出三条建议，任选其一或组合：
  1. 把 🎯 学习计划切到「雅思」或「冲刺」预设，加大每日练习量；
  2. 按差距把考试日推迟 4–8 周（建议里会给出具体日期）；
  3. 把目标分暂时调到 6.5。
- 建议**只做提示，不会自动修改**任何设置，改不改由你决定。

### 6.5 📚 基础知识库

入口：雅思备考的 **📚 基础** 子页（在「词汇」前面）。把 A2 → 7.0 要补的基础知识做成一篇篇知识卡片，共 **76 篇、438 道小测题**，全部原创。每篇都有**讲解、例句（点 🔊 朗读）、易错点、小测和相关跳转**，部分讲解配表格。

| 领域 | 内容 | 篇数 | 小测题数 |
|------|------|------|----------|
| 语法 · 核心 | A2 → B1：一般现在与现在进行时、一般过去与过去进行时、现在完成时、将来表达、冠词、可数与不可数、主谓一致、比较级、情态动词、被动语态、条件句、动名词与不定式 | 12 | 72 |
| 语法 · 进阶 | B2 → C1 写作语法：定语 / 名词性 / 状语从句、第三类与混合条件句、高级被动、名词化、分词结构、倒装与强调、hedging、平行结构、句子边界与标点、Task 1 / Task 2 的时态语态一致 | 12 | 72 |
| 题型技巧 · 听读 | 听力 5 篇（听前预测与同义替换、表格笔记填空、单选、配对与地图题、拼写与格式）；阅读 6 篇（略读扫读与时间分配、TFNG / YNNG、段落标题配对、信息配对、句子与摘要填空、单选） | 11 | 64 |
| 题型技巧 · 写说 | 写作 6 篇（Task 1 图表、流程图与地图、书信，Task 2 审题、PEEL 段落展开、连贯与衔接）；口语 5 篇（Part 1 / 2 / 3、流利度、词汇升级与 paraphrase） | 11 | 62 |
| 功能表达 | 写作 7 篇（趋势与数据、比较、因果、让步、举例、观点与 hedging、流程图与地图）；口语 1 篇 | 8 | 48 |
| 发音与构词 | 发音 6 篇（元音、辅音、单词重音、句子重音与弱读、连读、语调）；构词 4 篇（前缀、后缀与词性转换、学术词根、搭配规律） | 10 | 60 |
| Task 2 话题论点素材 | 教育、科技、环境、健康、工作、犯罪、媒体、城市、全球化、政府、文化、科学 12 个话题，每篇有常见题目方向、正反论点、核心词与搭配、示范段落；目录里归在「题型技巧 → 写作方法」，按「写作」或「口语」筛选都能找到 | 12 | 60 |
| **合计** | | **76** | **438** |

- **目录**：按领域分组（语法、题型技巧、功能表达、发音、构词），每组显示已读和完成的篇数；可以按水平（A2 / B1 / B2 / C1）和技能（听力 / 阅读 / 写作 / 口语）筛选，筛选条件会记住。
- **下一篇推荐**：目录顶部按水平从低到高、同一水平按学习顺序，推荐第一篇还没完成的；有筛选时只在筛选结果里推荐。
- **完成标准**：**已读，且小测最好成绩正确率 ≥ 60%**。读完讲解和易错点后点「读完了，标记已读」；交小测时还没标记已读会自动标上。
- **小测**：每篇 5–6 题，有单选、填空、改错三种。逐题作答、马上显示对错和解析，全部答完才能交卷；单选题每次打乱选项；可以「再做一次」，系统记最好成绩和做过的次数。填空、改错不区分大小写，多余空格和句末标点不影响，弯引号和直引号等同。
- **相关跳转**：去刷对应语法点的题、打开相关的新概念课文，或者跳到雅思写作、口语等子页。跳到刷题、教材等其他标签再回到雅思备考时，文章页和小测作答还在；切到雅思的其他子页则会回到目录。
- **计入学习**：每交一次小测记 1 次，计入 🎯 学习计划的「读」；基础期每周 2 篇的任务也按交小测的次数统计（见 6.2、6.3）。

### 6.9 听力、阅读错题的间隔复习

听力、阅读交卷后，**作答了但答错**的题会自动加进 **🔁 间隔复习**，和刷题、句型转换的错题一起按遗忘曲线到期重现。

- **哪些题会进去**：只有答错的题。**没作答的题不进**（练习模式常常只做一部分，全送进去会淹没复习队列）；答对的不进。已经在复习队列里的题，再次答错也不会重复加入，原来的复习进度不变。考试模式、练习模式都一样。
- **复习时看到什么**：
  - **阅读**：附上这道题所在段落的原文，再给题组说明、字数限制和题目。段落信息匹配题的答案就是段落字母，只给一段等于告诉你答案，所以给全文。
  - **听力**：附上答案所在的那一段脚本，可以点「🔊 播放原文」听；脚本默认收起，想看再展开，答完会自动展开。
  - 选择类题目点选项作答，填空类在输入框里写。
- **判分规则和原模块完全一致**：拼写、大小写、字数限制、数字写法、TFNG / YNNG 缩写等都按听力、阅读交卷时的规则判。答完显示你的答案、正确答案（含其他可接受写法和选项文字）、超字数提示、中文解析和原文依据，并在原文里把依据标黄（听力填空题标出答案词）。
- **不计入今日目标**：和其他复习一样，复习雅思错题不算进 🎯 学习计划的今日目标。
- 题库里某道题被删掉后，它会自动移出复习队列。

- **口语记录**（记录子页）里会显示每次作答的流利度指标和转写文本。
- **降级**：浏览器不支持语音识别（Chrome、Edge 可用）、当前离线、麦克风或识别服务被拒绝、网络出错时，会提示原因并改为只录音、不转写，练习照常进行。

### 6.12 成绩记录与分数估算

**记录**子页有**写作、口语、听力、阅读**四个标签：

- **写作 / 口语**：历次自评记录和 band 趋势，点开看原文与题目（口语另有转写和流利度指标）。
- **听力 / 阅读**：历次交卷的 band 趋势（实心点是考试模式，空心点是练习模式），列表显示时间、模式、原始分、错题数、用时和 band；点开一条可以看这次的错题（题干、正确答案、原文依据、解析；听力还显示你当时的答案，阅读记录不保存作答内容，只列正确答案），并可一键回到听力 / 阅读再练。题目后来被改动或删除时，只提示无法还原错题。
- 记录页顶部、雅思**总览计划**的「成绩概况」都显示六格：听力、阅读、写作、口语、最近一次词汇诊断、总分粗估。

**四项分数怎么来**：

每一项都按下面的顺序取，用到哪一种，格子下方会写明（例如「近 2 次整套成绩均分（站内模考 1 次、剑雅 1 次）」）：

| 顺序 | 取值 | 说明 |
|------|------|------|
| ① 整套成绩 | 近 6 周内有整套成绩时，取最近 ≤3 次的平均 | 整套成绩 = 🏁 站内模考里做完的那部分（听力 40 题、阅读 39 题折算、写作已按 Task 2 双倍加权）+ 录入的剑雅成绩 |
| ② 单项成绩 | 近 6 周没有整套时，取单项近 3 次的平均 | 听力、阅读只算考试模式交卷（练习只显示次数，不计分）；写作、口语是自评。模考拆写进各模块的记录不算在这里，免得一套模考被重复计算 |
| ③ 更早的整套 | 单项也没有时，用 6 周以前的整套成绩 | 会注明「已超过 6 周」，可能已过时 |

**总分估算**：四项都有分时，四项平均后按官方规则四舍五入到 0.5（.25 进为 .5，.75 进为整数）；缺了某几项时，先用已有几项的平均粗估（同样这样取整），并写明缺的是哪几项；一项都没有时不估分。

**🧭 我的水平**页的「🎓 雅思听说读写」卡片按听、说、读、写显示四项分数和总分估算，并说明是四项齐全还是缺了哪几项（有任一项记录或做过词汇诊断时才出现）。

这个总分**只是粗估**：写作、口语是自评，通常偏乐观；只靠单项练习时，站内单个听力 section 10 题、单篇阅读 13 题，一题就差 0.5–1 分。做过站内模考或录入剑雅成绩后，听力、阅读会改用整套成绩，比单项稳定得多，所以专项期起建议每做完一套剑雅就录入成绩。

### 6.13 全真模考

入口：**学 → 🎓 雅思备考 → 🏁 模考**。

- **组卷**：每次自动组一整套——听力 Part 1–4 各 1 个 section；阅读 3 篇（尽量易、中、难各 1 篇）；写作 Task 1（跟随档案：A 类图表 / G 类书信）+ Task 2；口语 1 个 Part 1 话题 + 1 张 Part 2 题卡及其 Part 3 追问。优先抽最近没做过的内容，全部做过后才会重复。按现有题库（听力每个 Part 5 个、易难度阅读 5 篇），连续 5 套的听力和阅读都不重复，第 6 套起开始重做；平时单独练过的听力、阅读也算「做过」，会被排到后面。
- **流程与计时**（按考试顺序，每部分做完保存后才能进入下一部分）：

| 部分 | 时间与规则 |
|------|------|
| 听力 | 约 30 分钟：每部分前有读题时间，只播一遍（浏览器朗读），最后约 2 分钟检查 |
| 阅读 | 60 分钟，3 篇共用一个倒计时，到时自动交卷 |
| 写作 | 60 分钟，两题共用；建议 Task 1 用 20 分钟、Task 2 用 40 分钟；写完做四维自评 |
| 口语 | Part 1 → 2 → 3，录音只在本页回听；做完四维自评 |

- **中途离开**：之后可以接着做；正在计时的部分被打断，只能「重新开始本部分」或「放弃本部分」，保证计时完整。
- **算分**：听力 4 个 section 共 40 题按换算表；阅读 3 篇 39 题折算到 40 题后换算；写作 = (Task 1 + 2 × Task 2) / 3 后向下取整到 0.5（Task 2 权重是 Task 1 的两倍，没写的一篇记 0 分）；口语四维平均向下取整到 0.5；总分为四项平均按官方规则取整。任一部分被放弃时不出总分。
- **出分**：和真实考试一样，进行中不显示分数，四部分都完成后统一出分，附错题复盘和与上一次模考的对比。各部分也会写进听力、阅读、写作、口语各自的记录（标注来自模考）。
- **计划**：冲刺期（W21–25）每周 1 套站内模考，另做 1 套剑桥雅思模考。
- **局限**：听力用浏览器语音合成，音色不如真人录音；写作、口语是自评；冲刺期请以剑雅真题模考成绩为主要参考。

### 6.14 导入自有资料

自己整理的雅思词汇、写作题、口语题可以导入系统，和内置内容一起出现在词汇、写作、口语子页里：

```bash
npm run import:ielts -- <文件或目录> --type vocab|writing|speaking
# 先加 --dry-run 试跑只校验；--name 指定分片名
```

- 词汇支持 CSV 或 JSON，写作和口语用 JSON；导入前会逐条校验字段，与内置内容或已导入内容**重复的词 / id 会报错，不会覆盖**。
- 导入的文件写到 `data/ielts/local/`，**只在本机使用，不会提交到仓库**。导入后要**重启服务**（停掉再 `npm start`）才能看到。
- CSV 模板、各类型字段要求和常见报错的改法见 [雅思自有资料导入.md](雅思自有资料导入.md)。

### 6.15 数据与范围

- 雅思备考数据按档案存在 `data/profiles/<档案名>/ielts.json`，**💾 数据备份**导出时一并包含；写作、口语记录各最多保留 500 条，听力、阅读作答记录各最多保留 300 条；基础知识库的已读和小测成绩也存在这里。听力、阅读的错题复习进度和其他错题一样存在复习队列（`srs.json`）。
- 目前**不包含**：AI 批改；整套限时模考（听力 4 个 Part 连做、阅读 3 篇 60 分钟），现在只有单个 section / 单篇的考试模式；听力的多选题（Choose TWO）和地图、流程图标注题。这些留到后续版本。

## 9. 常见问题 FAQ

**Q：打不开页面？**  
A：确认终端里 `npm start` 已运行，浏览器访问 `http://localhost:3737`。

**Q：刷新后进度还在吗？**  
A：在。进度写在本地 JSON；除非清空数据或删 `data/`。

**Q：没有声音？**  
A：检查系统音量与浏览器权限。课文句优先播 **原声 MP3**；单词播真人库或 TTS。TTS 需 Mac/Windows 已安装英文语音。若原声无法播放，可能是克隆时未执行 `git lfs pull`（见 [原声与发音.md](原声与发音.md)）。

**Q：🔊 为什么是机器声而不是原声？**  
A：内容与 LRC 课文句不完全一致时会降级为 TTS；单词单独点击通常播单词发音而非整句原声。

**Q：情景对话左侧显示「没有匹配的场景」？**  
A：硬刷新页面（`Cmd+Shift+R`）；若从 Git 克隆，确认已 `git lfs install && git lfs pull` 并重启 `npm start`。侧栏应显示 8 个大类，其下为具体场景。

**Q：两台设备怎么同步？**  
A：系统无云同步。用 **数据备份** 导出 JSON，拷到另一台机器导入。

**Q：词典里全局词为什么没有教材例句？**  
A：全局词库约 2600 词，仅教材词有课内例句与句型；展开会标注「全局词库 · 仅词库释义」。

**Q：如何清除「知道了」后的欢迎引导？**  
A：浏览器清除站点数据中的 `nce-guide-dismissed`；或删对应 localStorage 项后刷新。

**Q：雅思口语录音会上传吗？**  
A：录音文件不会。录音只在本机浏览器里回听，不上传、不保存，关闭或刷新页面即消失；系统只记录作答时长和自评分。但如果你**手动勾选了「实时转写」**（默认关闭），Chrome 会把作答语音发到 Google 的在线识别服务做转写，转写文字和流利度指标会存进口语记录。不想让语音离开本机，保持「实时转写」不勾选即可。

**Q：雅思听力没有声音，或者考试模式按钮是灰的？**  
A：听力用浏览器的语音合成朗读，需要系统里装有英文语音。页面提示「没有可用的英文声音」时，在系统设置里安装英文（英国）语音后点「重新检测」；提示「浏览器拦截了朗读」时，在页面上再点一次播放。没有英文声音时考试模式不可用，可以用练习模式直接看脚本做题。

**Q：雅思口语页没有录音功能？**  
A：浏览器不支持录音时会隐藏录音，其余练习照常可用。请确认已允许麦克风权限；另外浏览器只在 `localhost` 或 HTTPS 页面下开放麦克风，用局域网 IP 通过 http 访问时无法录音。

**Q：雅思分数估算准吗？**  
A：只是粗估。每项优先用近 6 周的整套成绩（站内模考、录入的剑雅成绩），没有时才用单项练习近 3 次（听力、阅读只算考试模式）；缺项时按已有几项粗估并写明缺了哪几项。写作、口语是自评，通常偏乐观；单项练习题量小、波动大。做完剑雅记得录入成绩，估分会准很多（见 6.12）。

**Q：雅思听力、阅读做错的题去哪复习？**  
A：交卷后作答了但答错的题会自动进 **🔁 间隔复习**，没作答的不进；复习时附原文段落或脚本，判分规则和原模块一样，不计入今日目标（见 6.9）。

**Q：我是开发者，如何加题/加课？**  
A：见 [README.md](../README.md)「如何扩充题库」与 `docs/changes/` 变更说明。
