# Change：雅思备考 MVP

日期：2026-11-24
范围：新增「🎓 雅思备考」标签（计划 + 词汇 + 写作 + 口语 + 记录），并接入学习计划、水平页、查词典、首页与数据备份
设计契约：[docs/design/ielts-prep-mvp-20261124.md](../design/ielts-prep-mvp-20261124.md)

## 背景

系统原本围绕新概念 1–4 册做「学 → 练 → 复习」闭环，没有面向考试的主线。现在的学习目标是：从 **A2** 起步，用 **26 周**（默认考试日 2027-05-24，可改）考到 **雅思 7.0+**，默认 A 类，可切 G 类。

需要解决三件事：

1. 把现有功能按雅思备考节奏重新排成每日任务，并能看到离考试还有多远、当前阶段是否跟上；
2. 补上现有系统没有的雅思写作、口语练习和雅思高频词；
3. 水平页原来的 CEFR 只分到「B1+」，高段水平被低估，需要补齐并给出雅思分数粗估。

**如实说明**：A2 到 7.0 要跨 B1、B2、C1 三档，约需 **600 小时**有效学习，相当于 26 周每天 **3–3.5 小时**。时间线非常激进，计划里用第 8、14、20 周三个检查点兜底，没达标时给出调整建议。

## 已定决策

| # | 决策 | 理由 |
|---|---|---|
| D1 | 新增顶层标签 `ielts`（🎓 雅思备考），归入「学」组，面板内自带子导航 | 雅思是主线目标，需要一个入口 |
| D2 | **不改** `data/global-vocab.json`；另做雅思词汇诊断，按 B1 / B2 / C1 分段抽样估算覆盖率 | 保住「总词汇量」历次成绩的可比性，高段测量交给雅思词表 |
| D3 | 雅思词汇作为查词典新来源 `ielts`（教材 > extras > global > ielts，雅思词只补充新词）；背单词复用 `/api/words/rate`、`/api/words/spell` | 掌握度、间隔复习、活动统计全部复用，侵入最小 |
| D4 | 录音只存在浏览器内存（MediaRecorder + blob URL），不上传、不落盘；服务端只存时长和自评分 | 隐私、体积，JSON 存储保持简单 |
| D5 | 写作、口语自评取四维平均后**向下取整到 0.5**；总分估算按官方规则四舍五入到 0.5（.25 进为 .5，.75 进为整数） | 自评偏乐观，向下取整更保守 |
| D6 | 26 周模板固定；实际周数 = ceil((考试日 − 开始日) / 7)，夹在 [4, 52]；第 i 实际周映射到模板第 round((i−1)×26/实际周数)+1 周 | 改考试日后计划自动压缩或拉伸 |
| D7 | 官方真题和评分标准原文不入库，题目、范文、例句全部原创；`data/ielts/local/` 不入库，加载器同 schema 读取 | 版权 |
| D8 | 学习计划新增 `ielts` 预设；写技能追加 `ielts-writing`，说技能追加 `ielts-speaking`，雅思词汇经 `words` 计入「记」 | 不改变其他预设的行为 |
| D9 | CEFR 改为 Pre-A1 / A1 / A2 / B1 / B2 / C1，取消「B1+」，并注明总词汇量测试高段词量有限，C1 以上看雅思词汇诊断 | 「B1+」低估高段水平 |

补充约定：

- 检查点（模板第 8 / 14 / 20 周）比较最近一次词汇诊断对应段覆盖率与写作、口语近 3 次自评均值：B1 段 ≥ 70% 且写 / 说 ≥ 5.0；B2 段 ≥ 60% 且 ≥ 5.5；C1 段 ≥ 50% 且 ≥ 6.5。未达标时给出三条建议（切「雅思」或「冲刺」预设加量 / 考试日推迟 4–8 周并给出日期 / 目标暂调 6.5），**只提示，不自动修改**。
- 外部资料任务（剑雅听力、阅读、全套模考）`kind: external`，只能手动打勾，按日期记录。

## 已知边界

- 写作、口语分数完全来自自评，检查点和分数估算都依赖自评质量；用向下取整和「拿不准选低一档」的引导降低偏差，但不能替代真实批改。
- 本期没有雅思题型的听力、阅读，总分估算只是粗估。
- 录音刷新或关闭页面即丢失，这是 D4 的有意取舍。
- 浏览器只在 `localhost` 或 HTTPS 下开放麦克风，局域网 IP 走 http 访问时无法录音。
