## 口径摘要

- 听力：考试模式（含模考）每题都算、未作答记错；练习模式只算作答了的题。
- 阅读：只算考试模式（记录不存作答内容）。
- 题目改动后对不上的记录跳过，计入 `skipped`。
- 最弱项：至少 8 题、正确率 < 70% 的题型，按正确率升序取 3 个。
- 听力错误原因按优先级：未作答 → 超字数 → 选项选错 → 单复数 → 数字 → 拼写 → 其他。

## 验证

- `test:ielts-weakness` 25 项通过；变异检查 4 处（拼写容错边界、原因优先级、练习模式计入空题、样本阈值）各有用例失败。
- 合入后全部 IELTS 测试通过（api 89、ai 16、weakness 25、external 14、mock 28、reading 30、listening 24、knowledge 26、srs 26、ielts 31），`npm run validate` 0 错误 0 警告。
- 真实题库核对：映射到的知识库文章 id 全部存在；`gradePassage` 结果带题型。
- 端到端（临时档案 + 真实 `server.js`）：交一份听力 Part 1（拼写、留空、单复数各错 1）、一份 Part 2（错 2 道选择）、一篇阅读（TFNG 错 3），统计结果为错误原因「选项选错×2、未作答×1、单复数×1、拼写×1」，TFNG 2/5 因不足 8 题不进最弱项，`days=3` 返回 400。
- 前端（agent 在 worktree 中）：本机 headless Chrome 跑了 10 个场景（最弱项、原因、分项条、窗口切换与竞态、看讲解深链、去练、两种空状态、500 / 1000px 无横向滚动）。
- 未测：真机移动端、390px 宽。

## 已知限制

- 阅读没有错误原因（记录不存作答内容）；要做需要先改阅读交卷记录。
- 题量还少时大多数题型不到 8 题，「最需要补的」会是空的，属预期。
- 弱项还没有随时间的变化趋势。
