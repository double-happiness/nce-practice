# Change：雅思备考第三批功能

日期：2026-11-25
范围：「🎓 雅思备考」新增「📚 基础」子页（基础知识库）；听力、阅读错题自动进入「🔁 间隔复习」；记录页、水平页、总览接入听力和阅读成绩，总分估算改为听说读写四项；学习计划与 26 周计划接入基础知识库；词汇、写作、口语、听力、阅读题库扩充

## 背景

第二批做完后还有三处明显的缺口：

- **A2 起步缺基础知识**：站内只有练题，没有成体系讲语法、题型技巧和常用表达的内容，做错了只能看单题解析。
- **听力、阅读做错的题没人管**：刷题、句型转换、情景对话的错题都会进间隔复习，听力和阅读交完卷错题就散了。
- **听力、阅读没接入总分**：第二批「已知限制」里写过，`/api/ielts/summary` 的总分估算只用写作、口语自评，记录页也只有写作、口语；而写作、口语是自评、偏乐观，只有听力、阅读是客观判分。

另外听力只有 8 个 section、阅读 6 篇，26 周计划专项期很快就开始重做。

系统只给本人自学用，本批的取舍据此而定：

- 知识库小测的答案随文章下发，在前端本地判分，服务端只校验并记录分数；懂行的人在开发者工具里能看到答案，单人自学可以接受。
- 错题复习只收**作答了但答错**的题，未作答的不收：练习模式常常只做一部分，全收会淹没复习队列。
- 听力、阅读的分数**只算考试模式**：练习模式能暂停、重播、看脚本，成绩偏高，只计次数不计分。

本批同时扩充了题库：词汇 1201 → 1641、写作 74 → 94、口语 64 → 96 条、听力 8 → 16 个 section（80 → 160 题）、阅读 6 → 14 篇（78 → 182 题），新增知识库 76 篇、438 道小测。

## 已知限制

- **模考模块尚在开发**：未合入，本批不含；整套限时模考（听力 4 个 Part 连做、阅读 3 篇 60 分钟）目前仍只有单个 section / 单篇的考试模式。
- **电话号码带空格会按多个数字计入字数限制**：听力判分按空格切分计数，`900 247` 算两个数字，在「ONE WORD AND/OR A NUMBER」这类限制下判超字数。听力第二批的电话题在解析里提示了不要加空格，用户指南也写了；错题复习复用同一套判分，规则相同。
- **知识库**：小测答案随文章下发、前端本地判分；不读取 `data/ielts/local/`，`npm run import:ielts` 也不支持知识库；学习计划按交小测的次数计数，同一篇反复做也会累计，只标记已读不计数。
- **记录页阅读错题不显示「你的答案」**：阅读作答记录只存错题 id，不存作答内容。
- **`scripts/test-ielts-srs.js` 没有 npm 命令**：需要 `node scripts/test-ielts-srs.js` 直接跑。
- **真实发声未在无头环境验证**：知识库例句和复习页听力脚本的 🔊 只验证了会调用 `NCE.speak`，需要在真机上实际听一遍。
- **题量仍有限**：听力 16 个 section、阅读 14 篇，26 周计划专项期和冲刺期仍会重做；单个 section 10 题、单篇 13 题，估算 band 一题就差 0.5–1 分，只看趋势。
- **第二批遗留**：`docs/雅思自有资料导入.md` 的 Task 1 图表类型仍只列 bar / line / pie / table，工具实际已接受 process / map，说明待补。
- **站内帮助缓存**：本次改了 `public/help.html`（在 PWA 预缓存列表里），只做文档改动，没有升 `SW_VERSION`；静态资源走 stale-while-revalidate，已安装的 PWA 多刷新一次就能看到新内容。
