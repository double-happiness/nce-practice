📖 使用说明

新概念英语 1–4 册配套练习系统：教材、刷题、听写、词典、句型转换与复习闭环。Markdown 版见仓库 docs/用户指南.md。

1. 快速开始

npm install    # 首次需联网
git lfs install && git lfs pull   # 从 Git 克隆后拉原声 MP3
npm start      # 打开 http://localhost:3737

学习记录在本机 data/，无需账号。服务启动后断网仍可使用（原声/真人发音本地内置）。

5. 🔊 发音与原声课文

全站小喇叭按优先级自动选音源：

  1. 新概念英音原声 — 与课文 LRC 句一致时（教材页 🎧 原声课文）
  2. 真人单词发音 — 单词 / 短短语
  3. 浏览器 TTS — 以上都没有时
📌 教材页打开 🎧 原声课文：整课 MP3 播放，点击句子跳转并高亮。 276 课原声已内置，离线可用。顶栏语速只影响 TTS。

6. 💬 情景对话怎么用

进入 💬 情景对话 后，左侧为两层目录：

  1. 大类（8 个）— 居家社交、餐饮购物、出行旅游、职场学习、住房物业、健康运动、生活服务、休闲文娱
  2. 具体场景（73 类）— 如打电话、超市、机场、IT 工作等

点击大类名展开/收起，再点场景，右侧挑选对话练习。搜索框可搜大类或场景名。

7. 🎓 雅思备考

入口：学 → 🎓 雅思备考，子页为 总览计划 / 📚 基础 / 词汇 / 🎧 听力 / 📖 阅读 / 写作 / 口语 / 记录。

⏱️ 时间线如实说：A2 → 雅思 7.0 要跨 B1、B2、C1 三档，约需 600 小时有效学习，相当于 26 周每天 3–3.5 小时，节奏很紧；计划用三个检查点兜底。

开启备考

  • 默认 A 类、考试日 2027-05-24、目标 7.0，开启前可改，开启后也能改；A 类写作 Task 1 为图表题，G 类为书信。
  • 开启当天记为备考开始日；按「开始日 → 考试日」换算实际周数（4–52 周），改考试日后计划自动压缩或拉伸。
  • 开启后首页显示考试倒计时卡片。

每周 5–10 项任务，日均约 180–210 分钟（第 26 周约 90 分钟）。「剑雅」指《剑桥雅思》真题集，需自备。站内听力 20 个 section、阅读 17 篇，中后段仍会重做，属预期。

今日任务

  • 系统内任务按真实练习记录自动统计，做够即完成；点 「去做 →」 跳到对应功能。
  • 外部资料任务（剑雅听力 / 阅读 / 模考）做完后手动打勾，记在当天；也可以点「录成绩 →」到 记录 → 📘 剑雅 录入分数，保存时顺带打勾。
  • 站内听力、阅读任务按交卷次数统计（一个 section / 一篇记 1 次），不区分模式；基础知识库任务按交小测的次数统计，只标记已读不计数。
  • 🎯 学习计划新增「雅思」预设；雅思听力计入「听」、阅读和基础知识库小测计入「读」、写作计入「写」、口语计入「说」、背雅思词计入「记」。间隔复习里的雅思错题不计入今日目标。

📚 基础知识库

  • 共 76 篇、438 道小测，全部原创：语法核心（A2→B1）12 篇、语法进阶（B2→C1 写作）12 篇；题型技巧听读 11 篇、写说 11 篇；功能表达 8 篇；发音与构词 10 篇；另有 Task 2 话题论点素材 12 篇（12 个话题，正反论点、核心词与搭配、示范段落，目录里归在「题型技巧 → 写作方法」）。
  • 每篇有讲解、例句（点 🔊 朗读）、易错点、小测和相关跳转（去刷对应语法、打开新概念课文、跳到雅思写作 / 口语等子页）。
  • 目录按领域分组，可按水平（A2–C1）和技能筛选；顶部「下一篇推荐」按水平从低到高、同水平按学习顺序，推荐第一篇未完成的。
  • 完成 = 已读且小测最好成绩 ≥ 60%；交小测时会顺带标记已读。小测每篇 5–6 题（单选、填空、改错），逐题即时反馈，可再做一次，记最好成绩。
  • 每交一次小测计入学习计划的「读」1 次；26 周计划基础期每周 2 篇（第 1–4 周核心语法，第 5–8 周功能表达或题型技巧）。

词汇

  • 共 1641 词：学术通用 621 个，社会类、自然科技类话题词各 510 个（12 个话题各 85 个）；可按话题、CEFR 浏览。
  • 卡片背诵、拼写与 🔤 背单词共用掌握度和间隔复习；📕 查词典也能查到雅思词。
  • 🔗 搭配练习：每轮 10 题，从词条的搭配里挖掉目标词，看中文释义补词；4 选 1 和填空交替。
  • 📝 例句填空：每轮 10 题，用词条的原创例句挖空，看中文译文填词，原形或例句里的变形都算对。
  • 两种练习按当前话题 / CEFR / 关键词出题，每答一题计入背单词掌握度（对记「认识」、错记「不认识」）。
  • 雅思词汇诊断：B1 / B2 / C1 各抽 10 词，看英文选中文（4 选 1），给出各段覆盖率和错词；不影响 🌐 总词汇量的口径。

🎧 听力

  • 题库：20 个原创 section，Part 1–4 各 5 个，每个 10 题，共 200 题；Part 1 表格 / 笔记填空，Part 2 单选、匹配，Part 3 单选、匹配、句子填空，Part 4 笔记、摘要填空。
  • 用浏览器语音合成（TTS）朗读脚本，没有音频文件；只用英文声音、优先英音，不同说话人分配不同声音。
  • 考试模式：每组题前 30 秒读题 → 本组录音只播一遍（不能暂停、回放）→ 全部播完后 30 秒检查 → 自动交卷；中途切走页面考试中断，可转练习模式继续或放弃。
  • 练习模式：可暂停、上一段 / 重播本段 / 下一段、点段号跳播，语速 0.85–1.15 可调，可打开脚本对照。
  • 判分按雅思规则：填空有字数限制，超字数判错；拼写必须正确，单复数不同也判错；数字的不同写法都算对（如 28 / twenty-eight、7:45 / 7.45，由题库逐题列出）；电话号码不要加空格，900 247 会按两个数字计入字数而判错。
  • 复盘：原始分、折算 40 题分数和估算 band；逐题对错、正确答案、中文解析；脚本里高亮答案所在段落并标题号，点任意段重听。
  • TTS 不可用（浏览器不支持或没有英文声音）：页面提示原因，考试模式不可用；练习模式默认展开脚本，直接看脚本做题，交卷复盘照常。装好英文语音后可点「重新检测」。

📖 阅读

  • 题库：17 篇原创学术类文章（易 5 篇、中 5 篇、难 7 篇），每篇约 680–890 词、A–G 共 7 段、13 题，共 221 题。
  • 8 种题型：判断题（TRUE / FALSE / NOT GIVEN）、观点判断（YES / NO / NOT GIVEN）、段落标题匹配、段落信息匹配、单选、句子填空、摘要填空（原文取词或词库选词）、简答。
  • 考试模式 20 分钟倒计时，到时只提醒、不强制交卷；练习模式不计时。作答自动存草稿。
  • 在文章里选中文字可 🖍 高亮，点高亮处取消；高亮只在本次打开页面期间保留。
  • 交卷后点任意一题，展开中文解析，文章里高亮并滚动到原文依据句；结果页给出原始分、折算 40 题分数和估算 band（单篇 13 题，只看趋势）。
  • 判断题可写缩写（T / F / NG、Y / N / NG），两套不能混用；填空超字数判错，拼写须完全一致。

🔁 听力、阅读错题进间隔复习

  • 交卷后，作答了但答错的题自动进入 🔁 间隔复习；没作答的题不进，答对的不进，已在队列里的不重复加入。考试、练习模式都一样。
  • 复习时，阅读题附所在段落原文（段落信息匹配题给全文，免得泄题）；听力题附对应脚本段，可 🔊 播放，脚本默认收起、答完自动展开。
  • 判分规则和听力、阅读原模块完全一致（拼写、字数限制、数字写法、TFNG 缩写等）；答完给正确答案、解析，并在原文里标出依据。
  • 和其他复习一样，不计入今日目标。

写作

  • 题库共 94 题，全部原创并带范文：Task 2 共 60 题（5 种题型各 12，12 个话题各 5）；Task 1 A 类 22 题（柱状 4、折线 4、饼图 3、表格 3、流程图 4、地图 4）；G 类书信 12 封。
  • 流程图用方框和箭头画出各阶段（循环流程排成一圈）；地图两张对照，带图例和指北针。
  • 计时：Task 1 20 分钟、Task 2 40 分钟；实时字数，草稿自动存在本浏览器；Task 1 少于 150 词、Task 2 少于 250 词会提示。
  • 提交后四维自评（任务完成 / 任务回应、连贯与衔接、词汇、语法），每维对照 4–8 分五档说明和检查清单打分，拿不准选低一档；范文提交前隐藏，自评后对照。
  • 本篇分数 = 四维平均向下取整到 0.5，如 6 / 6 / 5.5 / 5.5 → 5.5。

口语

  • 题库共 96 条：Part 1 共 48 个话题 × 4 题；Part 2 题卡 48 张，各配 4 道 Part 3 追问；全部带参考答案。
  • Part 1 逐题答；Part 2 准备 60 秒 → 作答 120 秒；Part 3 追问。
  • 浏览器支持时可录音回听。录音只在本机浏览器里，不上传、不保存，刷新或关闭页面即消失；系统只记作答时长和自评分。
  • 四维自评：流利与连贯、词汇、语法、发音，同样 4–8 分五档，分数取法同写作；打完分再看参考答案。
  • 实时转写（默认关闭，需手动勾选）：勾选「实时转写」后，作答时边说边出文字，结束后统计词数、WPM、填充词、重复、长停顿（超过 3 秒）、连接词，只作流利度自评参考，不自动打分；口语记录里会显示转写和各项指标。
🔒 开启实时转写前请知道：识别语言是 en-US；Chrome 会把作答语音发到 Google 的在线识别服务（需联网），录音文件本身仍只保存在页面内存里；转写文字和指标会随自评存进 ielts.json。浏览器不支持、离线或权限被拒时自动改为只录音。

导入自有资料

npm run import:ielts -- <文件或目录> --type vocab|writing|speaking

词汇支持 CSV / JSON，写作、口语用 JSON；先校验字段、与已有内容判重，不覆盖。导入到 data/ielts/local/，只在本机使用、不入库，导入后重启服务生效。详见 docs/雅思自有资料导入.md。

成绩记录与分数估算

  • 记录子页有写作、口语、听力、阅读四个标签：听力、阅读显示 band 趋势（实心为考试模式、空心为练习模式）和历次成绩，点开可看当次错题并跳回再练；阅读记录不保存作答内容，只列正确答案。
  • 📘 剑雅标签：录入剑桥雅思等外部真题成绩。听力、阅读填答对题数 /40 自动换算 band（阅读按 A 类表，可改按书后换算表填；G 类阅读须直接选 band），写作、口语填 0–9 的 band；录错了删掉重录。
  • 四项分数：近 6 周有整套成绩时优先用整套（🏁 站内模考做完的部分 + 录入的剑雅成绩，取最近 ≤3 次平均）；没有时用单项近 3 次——听力、阅读只算考试模式（练习只计次数），写作、口语为自评；模考拆写进各模块的记录不重复计算。每格下方写明用的是哪种。
  • 总分估算：四项齐全时取平均，按官方规则取整（.25 进 .5，.75 进整数）；缺项时按已有几项粗估，并写明缺了哪几项。🧭 我的水平、雅思总览和记录页都显示四项分数与总分。
📌 分数估算只是粗估：写作、口语是自评，通常偏乐观；只靠单项练习时，站内单个听力 section 10 题、单篇阅读 13 题，波动大；做完剑雅记得录入成绩，听力、阅读会改用整套成绩。数据存在当前档案的 ielts.json，随 💾 数据备份导出。目前还没有 AI 批改。

🎯 弱项

  • 按近 30 / 60 / 90 天统计听力、阅读各题型正确率（听力另按 Part，阅读另按难度）；听力考试模式每题都算，练习只算作答的题；阅读只算考试模式。
  • 「最需要补的」：至少 8 题、正确率低于 70% 的题型里最低的 3 个，附建议、「📚 看讲解」（直达基础知识库对应文章）和「去练」。
  • 听力错题按原因归类：未作答、超字数、选项选错、单复数、数字 / 日期、拼写、其他；最常见的原因附对应讲解。

写作 AI 批改（可选）

  • 服务端配置了 ANTHROPIC_API_KEY（.env + npm run start:env）才会出现；写作交卷后或在 记录 → 写作 里点「🤖 AI 批改」，约 30–90 秒。
  • 给出四项分数与评语、总评、主要问题、逐句修改和一段示范改写；总分按四项平均向下取整到 0.5。
  • 每篇默认只批一次，「重新批改」会再计费；每天最多 20 次。单篇约 $0.07–0.13，作文会发送到 Anthropic 处理。
  • AI 分数只作参考，不计入总分估算，也不替代自评。

全真模考

  • 入口：雅思备考 → 🏁 模考。一键组一整套：听力 4 个 section、阅读 3 篇、写作 Task 1 + Task 2、口语 Part 1–3，优先抽最近没做过的；按现有题库，连续 5 套的听力、阅读不重复。
  • 按考试顺序限时连做：听力约 30 分钟（只播一遍）、阅读 60 分钟、写作 60 分钟、口语 Part 1 → 2 → 3；中途可离开后续做，计时中的部分被打断只能重做或放弃。
  • 四部分完成后统一出分：听读按换算表，写作按 (Task 1 + 2 × Task 2) / 3，总分按官方规则取整；附错题复盘与上次对比。冲刺期计划每周 1 套。

10. 常见问题

打不开页面？
确认终端已运行 npm start，访问 http://localhost:3737。
没有发音？
检查音量。课文句优先原声 MP3；单词用真人库或 TTS。TTS 需已安装英文语音。
为什么是机器声不是原声？
内容与 LRC 课文句不一致时会用 TTS；单独点单词通常播词发音。
情景对话左侧是空的？
硬刷新（Cmd+Shift+R）；确认 npm start 已重启。正常应显示 8 个大类及其下场景。
克隆后原声播不了？
需安装 Git LFS 并执行 git lfs pull，见 docs/原声与发音.md。
两台设备怎么同步？
无云同步。用数据备份导出 JSON，在另一台导入。
断网能用吗？
可以。本机服务在跑即可；不访问外网 API。例外：雅思口语的「实时转写」（默认关闭）开启后要联网，离线时自动改为只录音。
雅思口语录音会上传吗？
录音文件不会，只在本机浏览器里回听，不上传、不保存，刷新或关闭页面即消失。只有手动勾选了「实时转写」时，Chrome 会把作答语音发到 Google 识别服务做转写；不勾选就不会。
雅思听力没声音 / 考试模式是灰的？
听力用浏览器语音合成，需要系统装有英文语音。提示没有英文声音时，装好英文（英国）语音后点「重新检测」；提示浏览器拦截朗读时，在页面上再点一次播放。没有声音时可用练习模式看脚本做题。
雅思口语页没有录音？
浏览器不支持时会隐藏录音。请允许麦克风权限；浏览器只在 localhost 或 HTTPS 下开放麦克风，用局域网 IP 走 http 访问时无法录音。
全局词为什么没有教材例句？
仅教材收录词有课内例句与句型；全局词展开会标注「仅词库释义」。
